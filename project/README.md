## 本輪實作

關門 → 開門見左側現代神主枱 → 選擇先看左邊或去見角色 → 玄／九爺對白與主題 → 日期／時間 → 核對 → 真正計算 → 5秒盤面星芒揭盤 → 紫微十二宮／宮星閱讀 → 修改重算。

所有片尾等使用者，不自動選答案、送表或排盤；有真盤ready才進揭盤，結果不鎖5秒。圓盤是演出道具，不是計算出的十二宮。

場景以cover鋪滿螢幕，不用純色邊或模糊兩翼；圖片與影片共用焦點，寬螢幕角色26%、神主枱29%。會裁去部分家具、身體或盤外框，不能同時保證整張原圖完整；480px素材放大仍會變軟。原來並排的影像／表格改為同一個場景，透明深色細框、同一套按鈕與輸入欄；資料填寫時背景靜止。刪去播放／暫停／重播鈕、無聲及載入等常駐提示，次要說明收在原生details。窄屏命盤區支援方向鍵左右捲動。必要輸入標籤、驗證錯誤、排盤規則及不保存／文化閱讀界線仍在。關閉、對白選項及必要表單操作不是演出控制，不會一併刪去。

唯一演出鈕為`略過`：停片、卸載片源、停聲，這一頁後續階段也不暗播；不跳過資料核對，不填答案、不算盤。關閉／Esc清空本次輸入及演出。初次／動態減少動態保留；關閉偏好不自行開播。

音效是原生Web Audio產生的三種低音量短提示，最長1.3秒；不是配音或背景樂，未購買或下載音源。只在可信點擊解鎖，播放失敗仍可繼續；略過、換場、關閉、分頁hidden或減少動態會停聲。數位圖形／節點檢查不等於實際揚聲器聽驗。

修訂2獨立覆核發現UI060-A01（緩衝未停短聲）及A02（延遲啟用後漏首次短聲），該候選未收口。修訂3只修音效：loading等非playing狀態立即停聲並取消待播；成功解鎖後只有同一未被取消的playing回合可補首次短聲，換場／關閉／略過／hidden／reduced不會復活舊cue。沿原函式修正，不新增播放器或音效依賴。

盤面七處金白星芒隨4度道具轉動漸亮，約1–3.9秒維持強光，4.5秒後收光；最後半秒及減少動態靜態圖無新增光。不是手指發光、快速頻閃或實際太陽亮度校準，星點位置亦不是使用者計算命盤。
